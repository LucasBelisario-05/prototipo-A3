# Apple Human Interface Guidelines

Siga estas regras sempre que criar ou revisar interface.

## Regras principais

1. **Fonte do sistema**: use a fonte do sistema (San Francisco; em web, `-apple-system, BlinkMacSystemFont, system-ui`). Prefira estilos de texto (título, corpo, legenda) a tamanhos fixos.
2. **Cores semânticas**: use cores por função (fundo, texto primário/secundário, destaque, destrutivo), não valores fixos. Toda cor deve ter variante para **modo claro e escuro**.
3. **Área mínima de toque**: **44x44 pt** para qualquer elemento interativo.
4. **Componentes nativos**: prefira componentes nativos da plataforma (ou o equivalente mais próximo) a controles customizados.
